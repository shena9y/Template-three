# Shena9y — HTML & CSS Template Three

A full landing-page template built as the third training project from the **Elzero Web School** HTML & CSS curriculum. It packs a rich set of sections — hero, articles, gallery, features, testimonials, team, services, skills, events, pricing and more — into a single responsive page, plus a live countdown timer in vanilla JavaScript.

## ✨ Features

- 🧲 **Mega menu** in the header with two-column link layout
- 🦸 Animated hero/landing section
- 📰 Articles, 🖼️ gallery, 🌟 features and 💬 testimonials sections
- 👥 Team members, 🛠️ services and 📊 animated skills progress bars
- ⏳ **Live countdown timer** (days/hours/minutes/seconds) powered by vanilla JS
- 💵 Pricing plans & work-steps sections with dotted separators
- 📱 Fully responsive with the Cairo Google Font

## 🛠️ Tech Stack

- **HTML5** — semantic, sectioned markup
- **CSS3** — custom stylesheet (`shena9y.css`) + normalize.css
- **JavaScript (ES6)** — countdown timer (`js/main.js`)
- **Font Awesome 6** — icons (locally hosted)
- **Google Fonts — Cairo** — typography

## 📂 Project Structure

```
├── index.html        # All sections in one page
├── js/
│   └── main.js       # Countdown timer
├── css/
│   ├── shena9y.css   # Main styles
│   ├── normalize.css # CSS reset
│   ├── all.min.css   # Font Awesome
│   └── fontawesome.css
├── imgs/             # Section images & backgrounds
└── webfonts/         # Font Awesome fonts
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/shena9y/Template-three.git
   ```
2. Open `index.html` in your browser — no build step required.
